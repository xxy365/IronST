## STLexer.g4

IEC 61131-3 Structured Text 词法文件，`caseInsensitive = true`。

### 关键字（必须在 IDENTIFIER 之前定义）

**程序组织**: `PROGRAM`, `END_PROGRAM`, `FUNCTION`, `END_FUNCTION`, `FUNCTION_BLOCK`, `END_FUNCTION_BLOCK`, `CONFIGURATION`, `END_CONFIGURATION`, `RESOURCE`, `END_RESOURCE`, `TASK`, `ACTION`, `END_ACTION`

**变量声明**: `VAR`, `END_VAR` 及其 8 种作用域变体（`VAR_INPUT`, `VAR_OUTPUT`, `VAR_IN_OUT`, `VAR_GLOBAL`, `VAR_EXTERNAL`, `VAR_TEMP`, `VAR_ACCESS`, `VAR_CONFIG`）, `CONSTANT`, `RETAIN`, `NON_RETAIN`, `AT`

**控制流**: `IF/THEN/ELSIF/ELSE/END_IF`, `FOR/TO/BY/DO/END_FOR`, `WHILE/END_WHILE`, `REPEAT/UNTIL/END_REPEAT`, `CASE/OF/END_CASE`, `RETURN`, `EXIT`

**逻辑运算**: `AND`, `OR`, `XOR`, `NOT`, `MOD`

**布尔字面量**: `TRUE`, `FALSE`

**内置类型**: `BOOL`, `BYTE`, `WORD`, `DWORD`, `LWORD`, `SINT`, `INT`, `DINT`, `LINT`, `USINT`, `UINT`, `UDINT`, `ULINT`, `REAL`, `LREAL`, `TIME`, `DATE`, `TIME_OF_DAY`, `TOD`, `DATE_AND_TIME`, `DT`, `STRING`, `WSTRING`

**类型构造**: `TYPE`, `END_TYPE`, `STRUCT`, `END_STRUCT`, `ARRAY`, `REFERENCE`

**其他**: `WITH`, `ON`

---

### 字面量

| Token | 格式 | 示例 |
|---|---|---|
| `TIME_LITERAL` | (`T`/`TIME`) `#` 可选负号 + 若干时间分量 | `T#1h30m5s`, `TIME#-500ms` |
| `DATE_LITERAL` | (`D`/`DATE`) `#` YYYY-MM-DD | `D#2024-01-15` |
| `TOD_LITERAL` | (`TOD`/`TIME_OF_DAY`) `#` HH:MM:SS[.fff] | `TOD#12:30:00.5` |
| `DT_LITERAL` | (`DT`/`DATE_AND_TIME`) `#` YYYY-MM-DD-HH:MM:SS[.fff] | `DT#2024-01-15-12:30:00` |
| `BASED_INTEGER` | 基数 `#` 数字序列 | `2#1010`, `8#17`, `10#42`, `16#FF` |
| `REAL_LITERAL` | 含 `.` 或 `E` 的数字 | `3.14`, `1.0E-5`, `1_000.5` |
| `INTEGER_LITERAL` | 纯数字序列 | `42`, `1_000_000` |
| `STRING_LITERAL` | 单引号或双引号，内嵌转义用 `''` 或 `""` | `'hello'`, `"world"` |

`REAL_LITERAL` 必须在 `INTEGER_LITERAL` 之前定义（最长匹配原则）。

### 运算符与标点

```
:=  =>  REF=  **  <=  >=  <>
+ - * / = < > ( ) [ ] , ; .. # . : ^
```

### 特殊 Token

- `DIRECT_VARIABLE`: `%[IQM][XBWDL]?数字(.数字)*` — 硬件地址，如 `%IX0.0`, `%QW3`, `%MD100.5`
- `IDENTIFIER`: `[a-z_][a-z0-9_]*`（受 `caseInsensitive` 影响）

### 跳过规则

`(* ... *)` 块注释、`//` 行注释、空白符。

### Fragment

- `DIGIT`: `[0-9]`
- `TIME_COMPONENT`: `数字序列 + 后缀`，后缀为 `D`/`H`/`M`/`S`/`MS`

## STParser.g4

引用 `tokenVocab = STLexer`，入口规则 `compilationUnit`。

---

### 顶层结构

```
compilationUnit
  : (typeDecl | programDecl | functionDecl | functionBlockDecl | configurationDecl)* EOF
```

**5 种顶层元素**：

| 元素 | 结构 |
|---|---|
| `typeDecl` | `TYPE (id : typeDef ;)+ END_TYPE ;` — 一个块内可定义多个类型 |
| `programDecl` | `PROGRAM id varDeclBlock* statementList END_PROGRAM` |
| `functionDecl` | `FUNCTION id : returnType varDeclBlock* statementList END_FUNCTION` |
| `functionBlockDecl` | `FUNCTION_BLOCK id varDeclBlock* (statement \| ; \| actionDecl)* END_FUNCTION_BLOCK` |
| `configurationDecl` | `CONFIGURATION id varDeclBlock* resourceDecl* END_CONFIGURATION` |

**注意**: `functionBlockDecl` 的 body 是 statement 和 actionDecl **混合排列**的（非语句列表）。

---

### Configuration 层

```
configurationDecl → resourceDecl*
  resourceDecl → RESOURCE id ON id varDeclBlock* taskDecl* programConfig* END_RESOURCE
    taskDecl       → TASK id (param := expr, ...) ;
    programConfig  → PROGRAM id (WITH id)? : id (param := expr, ...) ;
```

---

### 变量声明

**声明块**:

```
varDeclBlock
  : varScope varModifier? varDeclItem+ END_VAR
  | VAR_CONFIG varConfigItem+ END_VAR
```

**作用域** (`varScope`): `VAR`, `VAR_INPUT`, `VAR_OUTPUT`, `VAR_IN_OUT`, `VAR_GLOBAL`, `VAR_EXTERNAL`, `VAR_TEMP`, `VAR_ACCESS`

**修饰符**: `CONSTANT`, `RETAIN`, `NON_RETAIN`

**声明项**:

```
varDeclItem  : varName (',' varName)* : dataType (:= initialValue)? ;
varName      : id (AT DIRECT_VARIABLE)?    // 可选硬件地址绑定
```

逗号分隔的多个变量共享同一类型和初始值。

**初始值**:

```
initialValue
  : structInitValue          // (field := val, ...)
  | arrayInitValue           // [val, val, ...]
  | expression
```

---

### 类型系统

```
typeDef
  : structDef       // STRUCT varDeclItem+ END_STRUCT
  | enumDef         // (Item, Item, ...)
  | subrangeDef     // TypeName(bound..bound)
  | dataType
```

**dataType**:

```
dataType
  : typeName ('(' expr ')' | '[' expr ']')?    // 带大小参数: STRING[80], STRING(80)
  | ARRAY '[' subrange (',' subrange)* ']' OF dataType
  | REFERENCE TO typeName
```

**enumDef**:

```
enumDef   : '(' enumItem (',' enumItem)* ')'
enumItem  : id (= expr)?    // 可选显式枚举值
```

**subrange**:

```
subrange       : subrangeBound .. subrangeBound
subrangeBound  : -? (INTEGER_LITERAL | BASED_INTEGER)
```

---

### 语句

```
statementList : (statement | ;)*

statement
  : assignmentStmt    ;
  | refAssignStmt     ;
  | callStmt          ;
  | returnStmt        ;
  | exitStmt          ;
  | ifStmt      ;?
  | forStmt     ;?
  | whileStmt   ;?
  | repeatStmt  ;?
  | caseStmt    ;?
```

复合语句后面的分号可选。

**各语句**:

| 语句 | 语法 |
|---|---|
| 赋值 | `variable := expression` |
| 引用赋值 | `variable REF= expression` |
| 调用 | `(builtinType \| variable) '(' paramList? ')'` |
| RETURN | `RETURN` |
| EXIT | `EXIT` |
| IF | `IF expr THEN stmts (ELSIF expr THEN stmts)* (ELSE stmts)? END_IF` |
| FOR | `FOR id := expr TO expr (BY expr)? DO stmts END_FOR` |
| WHILE | `WHILE expr DO stmts END_WHILE` |
| REPEAT | `REPEAT stmts UNTIL expr END_REPEAT` |
| CASE | `CASE expr OF caseElement+ (ELSE stmts)? END_CASE` |

**CASE 细节**:

```
caseElement : caseLabel (',' caseLabel)* : statementList
caseLabel   : subrangeBound (.. subrangeBound)?    // 1 或 1..5
            | id (. id)?                           // 枚举值，支持限定名
```

**参数传递**:

```
paramList       : paramAssignment (',' paramAssignment)*
paramAssignment : id => variable        // 命名输出参数
                | id := expression      // 命名输入参数
                | expression            // 位置参数
```

---

### 表达式（优先级从低到高）

```
expression     : xorExpr (OR xorExpr)*
xorExpr        : andExpr (XOR andExpr)*
andExpr        : comparisonExpr (AND comparisonExpr)*
comparisonExpr : addExpr (compOp addExpr)?
addExpr        : mulExpr ((+|-) mulExpr)*
mulExpr        : unaryExpr ((*|/|MOD) unaryExpr)*
unaryExpr      : (NOT|-) unaryExpr | powerExpr
powerExpr      : postfixExpr (** unaryExpr)?
postfixExpr    : primaryExpr (call | index)*
               | builtinType(call)(index)*
primaryExpr    : literal | typedLiteral | variable | '(' expression ')'
```

**关键点**:

- `compOp`: `=`, `<>`, `<`, `>`, `<=`, `>=`
- `-3**2` 解析为 `-(3**2)` = -9（幂优先于一元负号）
- `postfixExpr` 支持两种形式：普通后缀 `foo(args)[idx]`，以及 `builtinType(expr)` 形式（类型转换调用）
- `call` = `'(' paramList? ')'`，`index` = `'[' expressionList ']'`

**typedLiteral**:

```
typedLiteral      : typeName # typedLiteralValue
typedLiteralValue : -? (INTEGER_LITERAL | REAL_LITERAL)
                  | BASED_INTEGER
                  | TRUE | FALSE
                  | STRING_LITERAL
```

例: `DINT#-100`, `BOOL#TRUE`, `16#FF`

**variable**:

```
variable : id (^ | '[' exprList ']')* ('.' id (^ | '[' exprList ']')*)*
```

支持标识符、解引用 `^`、数组索引 `[i,j]`、成员访问 `.`，以及它们的任意组合：`arr[i].field^.name`

---

### 特殊语法点总结

1. `caseInsensitive = true` — 关键字大小写不敏感
2. `BASED_INTEGER` 支持 2/8/10/16 进制，下划线分隔
3. `STRING[80]` 和 `STRING(80)` 两种大小指定语法都支持
4. 枚举项可带显式值，CASE 标签可用限定枚举名
5. `varDeclItem` 逗号分隔声明多个变量共享类型
6. `functionBlockDecl` 的 body 混合 statement 和 actionDecl
7. 一个 `TYPE...END_TYPE` 块可定义多个类型
