# IronST 语言参考（0.1.0）

> 本文档从源码 (`ST.g4`、`SemanticAnalyzer`、`TypeMapper`、`ExpressionEmitter`、`ByteCodeGenerator`、运行时错误枚举及缺陷登记簿 `F11/F13` 所述已修路径) 整理而成。仅覆盖已实现特性；未实现项标 `[未实现]`，已知缺陷标 `[缺陷登记 Fxx]`。

---

## 1. 词法与字面量

| 类别 | 语法 / 规则 | 备注 / 源码线索 |
|---|---|---|
| 注释 | `(* ... *)` 多行；`//` 行注释 | `STLexer.g4` |
| 标识符 | 字母/下划线开头，大小写敏感 | `SemanticAnalyzer` 注册时按原名保存 |
| 整数 | 十进制、`2#...` 二进制；可带下划线分隔 | `LiteralParser` |
| 实数 | `REAL` → `float`、`LREAL` → `double` | 类型映射：`TypeMapper` |
| 字符串 | `'...'` 或 `"..."`；双写转义 `''` / `""`；**`$n/$t` 等转义暂未处理**（仅做双写转义） | `[缺陷登记 F11]` 字符串后端路径曾不可用，已修复 (`f5e414f`)；`StringFunctions.cs` 提供 `LEN/LEFT/RIGHT/MID/CONCAT/FIND/INSERT/DELETE/REPLACE` |
| 时间字面量 | `TIME#1s`、`DATE`、`TOD`、`DT` 映射为 `i64` 毫秒/天数占位，**无实际时钟计算** | `[缺陷登记]` §3.13 / `TimeLiteralParser` |

## 2. 数据类型

| ST 类型 | 底层位宽 / LLVM 类型 | 备注 |
|---|---|---|
| `BOOL` | `i1` | 1 bit |
| `BYTE` / `SINT` / `USINT` | `i8` | 8 bit |
| `INT` / `WORD` / `UINT` | `i16` | 16 bit |
| `DINT` / `DWORD` / `UDINT` / `ENUM` | `i32` | 32 bit |
| `LINT` / `TIME` / `DATE` / `TOD` / `LWORD` / `ULINT` | `i64` | 64 bit |
| `REAL` | `float` | 32 bit |
| `LREAL` | `double` | 64 bit |
| `STRING(N)` | `{ i32, [N x i8] }` | 可变 |
| `WSTRING(N)` | `{ i32, [N x i16] }` | 可变 |
| `ARRAY[lower..upper] OF T` | `[size x T]` | 多维支持 |
| `STRUCT ... END_STRUCT` | 命名结构体 `%Name` | `[缺陷登记 F5]` `=` / `<>` 已实现按值逐字段比较；`REFERENCE`/`STRING`/`WSTRING` 字段仍拒绝 (`E2003`) |
| `REFERENCE TO T` | 指针 (`ptr`) | `[缺陷登记 A2]` 空引用解引用已加 `NULLCK` (`0x95`) 保护，不再静默读槽 0 |

> **已知限制**：结构体布局按字母序 (`TypeMapper.GetSortedFields`)，非源码顺序 `[缺陷登记 B3]`；`typeId` 为 `byte`，超 255 静默回绕 `[缺陷登记 F9]`（策略已定，随 0B 一并处理，不提前修）。

## 3. 程序组织单元 (POU)

```iecst
PROGRAM Main ... END_PROGRAM
FUNCTION Add : INT ... END_FUNCTION
FUNCTION_BLOCK Counter ... END_FUNCTION_BLOCK
```

- `FUNCTION_BLOCK` 可声明 `VAR_INPUT` / `VAR_OUTPUT` / `VAR_IN_OUT` / `VAR` / `VAR_CONSTANT` / `VAR_RETAIN` / `NON_RETAIN` / `VAR_TEMP`。
- `FUNCTION_BLOCK` 的实例通过 `Name : BlockType` 声明为变量；成员访问 `Name.Q` / `Name.R` 已可编译运行（`F11` 修复后路径完整）。
- `ACTION` 普通解析已完成；通过外部库声明 `FB ACTION` 链路 `[缺陷登记 F4]` 仍挂起。

---

## 4. 变量与初始化

- `[缺陷登记 F3]` 显式初始值曾丢失，已修复：前端 `ConstantEvaluator` + `VariableInfo.InitialValue` + 字节码全局初始化器。
- 局部变量默认值初始化已在 `FrameBuilder.BuildPrologue` 增加：`DINT`→0、`REAL`→0.0、`BOOL`→FALSE、`STRING`→空指针防御（`A10` 层 1 已修）。
- `[缺陷登记 A10]` 未赋值 `REAL` 的 `<>` / 排序比较曾抛 `TypeError`，已修复：`BcValue.Compare` 增加 `Void` 防御分支（`Void` 参与比较时按零值规则处理，不再抛）。
- `[缺陷登记 A3]` `VAR_RETAIN` 只解析修饰符，无持久化/恢复逻辑；`[缺陷登记 A4]` `TIME`/`DATE` 缺类型化运算与时钟源。
- `VAR_GLOBAL` / `VAR_EXTERNAL` 语义已实现（`[缺陷登记 A8/A9]`），但 `.stmod` 跨模块链接仍未完成（`B1`）。

---

## 5. 运算与表达式

- 算术：`+ - * / MOD **`；`MOD` 有符号语义已修复（`IMOD`/`UMOD`），除零抛 `DivideByZero`。
- 比较：`= <> < > <= >=`。
- 逻辑：`AND OR XOR NOT`；`NOT` → `BOOL`。
- 类型提升：整数 + 整数 → 较大位宽；整数 + 浮点 → 浮点；浮点 + 浮点 → 较大位宽。
- 结构体 `=` / `<>`：只允许同命名结构体类型、可寻址左值；逐字段/逐元素 `GEP + load + icmp/fcmp`；拒绝不同类型、顶层数组、含 `REFERENCE`/`STRING`/`WSTRING` 字段、非左值（`[缺陷登记 F5]`）。
- 引用解引用：`p^` / `p^.field` / `r^ := ...` 已保护；复制空引用 (`q := r`) 不报错，报错发生在解引用点（`[缺陷登记 A2]`）。

---

## 6. 语句与控制流

- 赋值：`a := b`；聚合整体搬运到数组元素 `xs[0] := x` 已实现（`A9`，逐槽深拷贝）。
- `IF` / `ELSIF` / `ELSE` / `END_IF`
- `CASE value OF ... END_CASE`：值标签、区间标签（`4..6`）、枚举标签（`Color.Red` / `Red` 两种写法已支持，`B1` 修复）；`ELSE` 已支持。
- `FOR i := start TO end BY step DO ... END_FOR`
- `WHILE ... DO ... END_WHILE`
- `REPEAT ... UNTIL ... END_REPEAT`
- `RETURN` / `EXIT`
- `CONTINUE`：语法解析存在，代码生成路径未完整验收（`[缺陷登记 A7]` 部分内容）。

---

## 7. 数组与结构体访问

- 数组下标：`arr[3]`、`m[1,2]`；`BOUNDS` 指令 (`0x94`) 已实现，越界抛 `ArrayBounds`（`C1` 修复）。
- 结构体字段访问：`p.X`；`AggregateRef` 统一处理栈槽 / 全局槽 × 静态 / 运行时地址（`A8` 修复）。
- 整体赋值：`xs[1] := xs[0]`（含动态下标、嵌套字段、自赋值重叠稳定）已修复（`A9`）。

## 8. 字节码与运行时（简要）

- 字节码文件 `.isb`：魔数 `IRST` (`0x49525354`)、版本头、结构体注册表、全局初始化、入口函数。
- `.stmod`：模块格式 `STMD`，区段表、元数据、函数索引；`v1` 已实现写入/读取/`mod build`/`inspect`，但静态链接未完成（`B1`）。
- VM 指令：算术/比较/跳转/栈/全局/聚合/字符串/`HCALL`/调试/`NULLCK` (`0x95`) / `BOUNDS` (`0x94`)。指令预算 `--max-instructions N`（默认不限）；超限抛 `InstructionBudgetExceeded`（退出码 1，不同于取消的 130）。
- 运行时错误类型（已细分）：`DivideByZero` / `ArrayBounds` / `NullReference` / `StackOverflow` / `SlotOverflow` / `TypeError` / `InstructionBudgetExceeded` 等。
- 宿主函数注册：`DefaultHostEnvironment` 默认注册 `Print` + 字符串标准函数；浮点数学函数（`sqrt`/`sin`/`log`/`fabs`）需宿主自行注入（`[缺陷登记 F13]` 裁定：不内置，走用户注入路径，注入路径已验收）。

---

## 9. CLI 与工程文件

- `compile <file.st ...>` → `.isb` / `.ll` / `.bc` / `.map.json`
- `run <file.st | .isb | .stmod | .stproj>` → 直接执行或先编译再执行；`--entry NAME`、`--stack N`（默认 8192）、`--timeout MS`、`--max-instructions N`
- `build <file.stproj>` / `expand <file.stproj>`：工程文件格式见 `.stproj`（XML）；多文件工程已实现（`B4` 修复）。
- `verify <file.st>`：只做前端分析，返回诊断，不生成字节码。
- `repl`：多行输入，空行执行，`exit` 退出。
- `mod build/link/inspect`：`.stmod` 操作。
- 退出码：`0` 成功、`1` 编译/运行/参数错误、`2` 工具缺失（`opt` 缺失）、`130` 取消（`Ctrl+C` / `--timeout`）。
