## 1. 环境要求

| 项目 | 要求 | 约束来源 |
|---|---|---|
| .NET SDK | `10.0.402` | `global.json: version=10.0.402`, `rollForward: latestFeature`, `allowPrerelease: false` |
| 操作系统（构建完整 sln） | Windows 10/11 | `net10.0-windows` 项目（IDE、StEditor、StEditor.Demo、IDE.Tests）在 Linux 不可构建 |
| 操作系统（运行 CLI/VM/LSP） | Windows / Linux / macOS | 代码跨平台，但 Linux/macOS **未纳入验证矩阵**，Linux 发布包 **未实跑** |
| NuGet 源 | 仅 `nuget.org`（`https://api.nuget.org/v3/index.json`） | `NuGet.config: clear + 单源`，避免用户级私有源 `XxyNuget` 造成 `NU1507` |
| 可选工具 | 系统 `opt` / `clang` | 仅 `--bc`（LLVM bitcode 输出）与二次优化需要；缺失 `opt` 时退出码 `2` |

> **不一致提示**：`README.md:72` 写“.NET 10.0 SDK 或更高版本”，实际受 `global.json` 严格约束（必须为 10.0.x feature band，不能跨大版本）；`README.md:73` 让人以为 Linux/macOS 完全支持，实际 Linux 只验证 9 个测试工程，macOS 无 CI job，IDE 仅 Windows。

## 2. 构建

### 基本命令

```bash
# 默认 Debug 配置
dotnet build IronST.slnx

# Release（CI 使用）
dotnet build IronST.slnx -c Release --no-restore
```

- 解决方案文件：`IronST.slnx`（XML 格式，无 `.sln`）。
- 测试工程：10 个（`IronST.*.Tests`），全部引用 `xunit.v3`、`coverlet.collector`（但 CI 未启用覆盖率收集）。
- 构建产物：`
  - `IronST.CLI` → `IronST.CLI.exe`（`AssemblyName=ironst`，实际发布为 `ironst(.exe)`）
  - `IronST.LanguageServer` → `ironst-ls(.exe)`
  - `IronST.IDE` → Windows-only WPF 应用（`net10.0-windows`）
  - `IronST.StEditor` → WPF 控件库（纯 UI，不依赖 Frontend）
  - `StEditor.Demo` → 独立 WPF Demo

### 当前构建状态

- `dotnet build`：`0 错误`；警告在 `global.json` + `NuGet.config` 落地后由 11 条 + `NU1507` 清零至 **0 警告**（`docs/生产发布检查表.md: D4`）。
- 没有 `TreatWarningsAsErrors`、没有 `.editorconfig`、没有格式化/分析器强制配置。
- `.stproj` 工程格式未独立文档化，仅在源码中可读。

## 4. 发布

### 脚本参数

```bash
bash scripts/publish.sh
# 可覆盖：VERSION=0.1.1  RIDS=win-x64  CONFIG=Release
```

- 默认 `VERSION` 从 `Directory.Build.props` 读取（`0.1.0`）；`VERSION` 只影响包名和目录名，**不传给 MSBuild**（程序集版本仍为 `0.1.0`/`0.1.0.0`）。
- 默认 `RIDS`：`win-x64 linux-x64`。
- 默认 `CONFIG`：`Release`（头部未文档化）。

### 发布产物

| 产物 | 路径 | 大小（实际文件） | 说明 |
|---|---|---|---|
| Windows 包 | `artifacts/dist/ironst-0.1.0-win-x64.tar.gz` | 87,917,598 字节 | self-contained 单文件；含 `ironst.exe` + `ironst-ls.exe` |
| Linux 包 | `artifacts/dist/ironst-0.1.0-linux-x64.tar.gz` | 64,752,506 字节 | 交叉发布；**未在 Linux 实跑** |
| 校验和 | `artifacts/dist/SHA256SUMS.txt` | — | `sha256sum` 格式 |

> 包内容：`ironst(.exe)`、`ironst-ls(.exe)`、`LICENSE`、`README.md`、`CHANGELOG.md`。**不包含 IDE**（WPF，仅 Windows）；**不包含开发样例 `test.st`**（脚本删除）；**不包含 `tools/opt`**（脚本删除，避免单文件 `Assembly.Location` 为空导致查找失败，`opt` 改由用户从 PATH 提供）。

## 5. 版本号与标签

- **单一事实来源**：`Directory.Build.props`（`Version`、`AssemblyVersion`、`FileVersion`、`InformationalVersion` 均为 `0.1.0` / `0.1.0.0`）。
- `.stmod` 元数据读取 `Assembly.GetName().Version`（`0.1.0.0`）。
- `InformationalVersion` 在构建时被 SDK 追加 `+<commit>`（如 `0.1.0+e2f9a4c...`），不是纯 `0.1.0`。
- 当前 **无 git tag**，`CHANGELOG.md` 只有 `0.1.0`（2026-10-23）。
- 发布流程建议（未执行）：`git tag -a v0.1.0` → `git push --tags` → `gh release create v0.1.0 --notes-file CHANGELOG.md`（`[检查表]:546-551`）。

## 6. 开发规范（简要）

- 每层只依赖编号更小的层（`README.md:567`）；实际 `BytecodeGen`（L2.5）引用 `Runtime.Shared`（L3），属表格内例外。
- 提交前运行 `dotnet test`（`README.md:569`）；无强制格式化/分析器配置，无 `TreatWarningsAsErrors`。
- 贡献流程：Fork → 分支 → 提交 → PR（`README.md:557-563`）。
- 无 `CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`.editorconfig`。
